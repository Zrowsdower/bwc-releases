# BWC Releases

Public release assets for **BWC (Bellwright With Chums)** — a self-hosted save-share manager for co-op survival games.

This repository contains release tags and downloadable Windows client binaries. Source code lives at [github.com/Zrowsdower/BWC](https://github.com/Zrowsdower/BWC) (private).

## Latest download

[bwc-windows-latest.zip](https://github.com/Zrowsdower/bwc-releases/releases/latest/download/bwc-windows-latest.zip)

Extract to `C:\` so you have `C:\BWC\`. Run `install.bat` as administrator.
